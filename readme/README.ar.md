# WPMMCC ATS — إضافة ووردبريس متعددة اللغات

**ووردبريس متعدد اللغات بأسلوب عملي: فحص، ربط، ترجمة.**

WPMMCC ATS إضافة ووردبريس تحوّل موقعًا أحادي اللغة إلى موقع متعدد اللغات. تفحص إضافات المحتوى والقوالب والقوائم للعثور على الحقول القابلة للترجمة، وتنشئ قواعد ترجمة قابلة لإعادة الاستخدام، وتدير علاقات المواقع بين اللغات، وتوفر محرر ترجمة يدوية كاملًا داخل لوحة تحكم ووردبريس. الترجمة الآلية متاحة مع العميل المرافق WPTSALL Client — دون حساب أو ترخيص أو ارتباط بمزوّد.

## الميزات
- فحص المحتوى — يكتشف الحقول القابلة للترجمة في المقالات والتصنيفات والبيانات الوصفية وإضافات المحتوى الخارجية والقوالب
- علاقات المواقع — يربط لغة المصدر بلغة الهدف، مع مواقع افتراضية لها بادئة URL خاصة
- محرر الترجمة اليدوية — ترجمة المقالات والحقول بالكامل داخل لوحة تحكم ووردبريس
- قواعد الترجمة — مجموعة قواعد واحدة يشترك فيها المحرر اليدوي وواجهة العميل
- واجهة العميل Protocol v2 — تتيح لعميل WPTSALL استلام المهام وكتابة النتائج
- حزم اللغات — الإنجليزية مدمجة؛ الصينية المبسطة قيد الإنجاز (انظر أدناه)

## المتطلبات
- ووردبريس 6.2 أو أحدث
- PHP 7.4 أو أحدث
- لا حاجة إلى حساب أو اشتراك أو مفتاح ترخيص

## التثبيت
1. نزّل ملف ZIP لأحدث إصدار من صفحة Releases في هذا المستودع ( أو اضغط المصدر بنفسك)
2. في لوحة التحكم: الإضافات → أضف جديدًا →ارفع الإضافة، ارفع الملف ثم فعّل الإضافة
3. افتح قائمة WPMMCC ATS في لوحة التحكم

## البداية السريعة (ترجمة يدوية، دون عميل)
1. افحص إضافات المحتوى أو أنشئ مجموعة قواعد ترجمة من صفحات إدارة WPMMCC ATS
2. أضف علاقة موقع: اختر لغة المصدر ولغة الهدف — يحصل الموقع الافتراضي على بادئة URL خاصة مثل /en_us/
3. افتح مقالًا في محرر الترجمة اليدوية وترجمه؛ يتحدث الموقع الهدف عند الحفظ

## الترجمة الآلية
للترجمة الآلية، ثبّت العميل المرافق WPTSALL Client (WebUI أو Desktop). يتصل بموقعك مباشرة برمز جهاز، ويستلم مهام الترجمة، ويستدعي مزوّد الترجمة الذي ضبطته، ثم يكتب النتائج. مستودع العميل: https://github.com/wpmmcc/wptsall-client

## Languages
الإنجليزية هي لغة المصدر المدمجة. حزمة الصينية المبسطة (zh_CN) قيد الإنجاز في languages/؛ بعد تجميع الفهرس، اختر لغة الموقع من الإعدادات → عام ليحمّلها ووردبريس تلقائيًا. لإضافة لغة أخرى، ترجم ملف languages/wpmmcc-ats.pot بمحرر PO الذي تفضله وقدّم مساهمتك.
